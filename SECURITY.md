# Security Policy

## Supported versions

Only the latest release (or the `main` branch while the project is pre-1.0) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include a description, affected versions, and steps to reproduce. This is a personal project maintained by one person: you can expect an initial response within 7 days, with no guarantee of a fix timeline.

## Scope

In scope: vulnerabilities in this repository's code and configuration, and secrets accidentally committed to it.
Out of scope: vulnerabilities in third-party dependencies (report them upstream) and issues that require physical access to the maintainer's machine.
